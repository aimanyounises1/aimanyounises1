## What I like working on

- **Full-stack systems:** connecting a clear interface to APIs, storage, and meaningful application behavior. CV Dataset Explorer is the most complete example to explore first.
- **AI features with explicit boundaries:** retrieval evaluation, inspectable outputs, controlled tool execution, and useful failure behavior.
- **Engineering decisions that can be reviewed:** setup instructions, tests, architecture notes, and honest descriptions of what a project can currently do.

The repositories include prototypes and learning work as well as more developed applications. Each featured project's documentation describes its setup, limitations, and verification scope.
